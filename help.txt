## 3️⃣ Mapping existing functionality (what to tell Cursor)

Since you don’t want to touch backend, just map old IDs → new ones in your Activity/Fragment/ViewModel. For Cursor, you can say something like:

> “This is the new layout `chef_page.xml`. Keep all existing backend logic but update the UI code to use these IDs:
>
> * Close button: `btnClose`
> * Tabs: `tabTable05`, `tabTable06`, `tabsContainer`
> * Order header: `tvTableHeader`, `badgeRunningLate`, `tvLastUpdated`
> * Items: `tvItemXName`, `tvItemXQty`, `tvItemXSize`, `tvItemXTips`, `switchItemX`
> * CTA: `btnMarkAllPrepared`
> * Bottom: `btnEatAway`, `btnParcel`
>   Use the existing ViewModel / API calls and bind their data into these views instead of the old layout.”

That should give Cursor everything it needs: **complete, valid XML + clear IDs** to wire your current logic into this new design.
